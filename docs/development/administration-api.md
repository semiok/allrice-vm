迁移 0111 已撤销旧租户 `admin` 角色，现有管理写入只维护 `member/viewer`。因此本批公司管理身份默认拒绝，等待明确的 4.0 授权来源。历史角色、请求指定的组织、客户端成员权限和 Guest 归属均不授予管理权限。平台管理员读取指定目标时，数据层校验真实组织和资源归属。读取无缓存。

## 按人灰度

写入字段为 `organizationId`、`personId`、`enabled`、`expectedRevision`。版本来自只读接口，历史空策略的版本是 `unpublished`。版本不符返回 409。入口先核真实登录与同源，DB 写事务重验平台身份。启用锁定有效成员记录，平台可以撤回旧成员资格留下的已选项。

仍使用当前设置键、同一事务锁和现有默认关闭策略。只更新指定的一组组织与人员，未变更的值不推新版本。回执中的 `audit.id`、`audit.occurredAt` 指向同事务审计，记录真实管理员、组织、人、请求 ID、前后状态和版本。失败没有成功回执。原批量 PUT 仍供现有运维，使用请求的 `revision` 作同锁版本检查，避免覆盖其间提交的按人变更。

## 个人 VM

摘要返回已持久化的生命周期、保盘状态、期次、端口数量和记录时间。实际端口、盘路径、密钥、挂载点、租约持有者、原生运行回执和执行内容不进入摘要。以实际宿主读回判断当前物理状态。

危险操作使用 `scripts/m1/person-vm-delete` 和它调用的既有 Worker loopback 入口。平台操作者使用自己的当前登录。保盘删除按确切 VM 和期次执行。销毁前先 `review`，再把同一目标的一次性确认凭证交给 `purge-disk`。现有服务在租约、盘身份和锁定写入下复核目标、操作者及确认，拒绝过期、跨登录、换代或重放。审计复用 `person_vm.platform.*`，记录操作者、目标人、VM、盘摘要以及结果。Web 只提供摘要读取。

## 诊断边界

管理轨迹和旧租户执行详情保留结构化状态、计时和用量事实。3.x 员工对话文本、原始事件摘要、工具查询/参数、stdout/stderr 和原始事件内容从管理响应移除。保留旧字段及脱敏占位。4.0 从同组织、工作区、人员和线程的已提交原生运行和生命周期事件取事实，本接口只投影原生运行时间点，未聚合 4.0 用量和任务时钟。诊断工件只列出可读业务成果，原始工具工件、项目快照及对象 ACL 拒绝的数据均不能预览或下载。

本切片属于 SaaS 门卫与单向审计。不涉及 DSH 原生权限、插件和生命周期改写，无数据库迁移。
